## Общие сведения

Репозиторий содержит в себе решение заданий 4-го спринта. Каждое задание имеет свою директорию и README-файл в формате markdown, если применимо. Схемы реализованы в формате plantuml, но имеют копию в формате png. Скрипты для запуска и инициализации заданий 2, 3 и 4 продублированы для поддержки docker и podman и расположены в директориях utils.
